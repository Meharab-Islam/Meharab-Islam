## 👋 About Me

I'm a **Flutter developer** based in Rajshahi, Bangladesh. I started learning Flutter back in **2019**, and have been building **production-grade mobile apps professionally since late 2022**. I care about clean architecture and maintainable code — enough that I built and published my own Flutter package (**`arch_wizard`**) for exactly that.

Right now I'm focused on **realtime communication systems** — SFU-based video/audio, interactive live streaming, and broadcasting — as the founder of **Softing Global**, where I also ship mobile apps built on top of that infrastructure.

- 🎯 Currently building a **video / audio / interactive streaming & broadcasting platform** from scratch
- 🧩 Author & maintainer of **arch_wizard** — a clean architecture + state management package for Flutter
- 🏥 Built an **investor management app** for Medipark Specialized Hospital
- 🚕 Built **Smooth Cars** — a ride-sharing app with realtime tracking
- 🕋 Contributed to **Hatem** — a Hajj & Umrah services app
- 🎓 Studying **CSE** at Times University Bangladesh
- 🌱 Also working with **Django** and **Golang** on the backend side
